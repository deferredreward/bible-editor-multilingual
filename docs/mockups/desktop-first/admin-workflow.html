Every book package — literal text, simplified text, translationNotes, Word links, Questions, and every referenced translationWords / translationAcademy article — moves through these steps in order.

There is deliberately no community check step here — that happens downstream, outside this tool, once a package is published. That absence is a decision, not an oversight.

A package is not done just because the text is drafted — it isn't finished until every translationWords / translationAcademy article it references is also translated. Final validation is where that gets checked.
