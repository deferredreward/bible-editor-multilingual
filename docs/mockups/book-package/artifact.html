This one needs a wider window

Judging a verse means holding the original, both translations and the notes in view at the same time. Below about 1000px something has to be hidden, and hiding any of it defeats the purpose — so the screen says so instead of quietly degrading.

Open this on a laptop or desktop, or widen the window. The phone equivalent of this screen is a different design: a queue of one note at a time, not a verse in full.
